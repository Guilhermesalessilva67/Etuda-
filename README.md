# Etuda-
O Estudaí é um site que propõe facilitar a vida dos estudantes por meio da organização das matérias, tarefas, prazos e revisões em um só lugar. Ele busca melhorar o foco, ajudar no planejamento semanal e permitir que o aluno acompanhe seu progresso nos estudos, respeitando seu próprio ritmo.
